# 已完成功能需求

## 基本需求

### ✅ 需求1：HTML 自动扫描与 URL 生成
- 自动扫描 Frontend 目录下所有 .html 文件
- 为每个 HTML 文件生成对应的访问 URL（`/static/html/{相对路径}`）
- 启动时自动扫描一次，支持手动触发扫描同步
- 扫描时自动提取页面 `<title>`、文件大小、修改时间
- 自动识别新增/更新/删除的文件并同步数据库

### ✅ 需求2：URL 增删改查管理 + 一键复制
- 列表展示所有 HTML 文件及 URL（支持关键词搜索）
- 编辑：可修改标题、URL、描述
- 删除：删除数据库记录（不删除磁盘文件）
- 一键复制：复制完整 URL 到剪贴板
- 预览：弹窗内 iframe 预览页面

### ✅ 需求3：技术栈
- 后端：Python Flask 框架
- 前端：Vue3 + Element Plus（配合 Vite + TypeScript）

## 系统通用需求

### ✅ 登录注册功能
- 用户注册：账号可为邮箱或手机号（至少一项）
- 密码二次哈希加密存储（werkzeug pbkdf2:sha256 + 随机盐 sha256）
- 登录：支持用户名/邮箱/手机号任一方式登录
- JWT token 鉴权

### ✅ 管理员账号
- 顶层管理员账号：admin / 1q2w3e4r
- 启动时自动创建

### ✅ 用户管理（管理员）
- 管理员可对任意用户信息进行任意修改（用户名、邮箱、手机号、密码、角色、启用状态）
- 支持新增、编辑、删除用户
- 不能删除自己和超级管理员

### ✅ 系统配置
- 前端参数保存到 SQLite 配置表
- 支持配置项的增删改查
- 程序启动时读取并同步

### ✅ 项目工程化
- 前后端分离（Frontend / backend 目录）
- 数据库 SQLite，文件位于 db/
- 启动入口 app.py
- run_app.bat 一键启动
- .env 管理隐私配置
- requirements.txt 管理依赖
